20g / 250ml — reusable artwork source pack

Files
back.svg: assembled nine-specimen grid with outlined Space Grotesk text.
front.svg: original editable DL mark and outlined Space Grotesk wordmark.
motifs/: nine standalone SVG specimens. Each SVG embeds the original raster
scan and applies a crop/clip and plum ink filter; these are not traced vectors.
motifs.json: exact crop coordinates and source/license mapping for every motif.
sources/coffea-arabica.jpg: unchanged downloaded botanical scan.
sources/provenance.json: Wikimedia Commons original URL and rights metadata.
fonts/: original Space Grotesk WOFF2 and full SIL Open Font License 1.1.
LICENSE-layout.txt: MIT license for original mark, layout and script.
generate-merch-artwork.py: reproducible composition source, intended to run
from scripts/ in the Devon Labs repository; requires fontTools and Brotli.

Text is outlined in the assembled SVGs so the letter shapes do not depend
on a substituted font. Retain the font license when redistributing the font.

All nine botanical motifs use the credited source scan, not the generated
illustrations in earlier concept drafts. The AI-generated shirt photograph
is a visual mockup; the SVGs here are the canonical reusable print composition.
Raster specimens retain the source scan's available detail. Confirm acceptable
print size and quality with the printer before manufacturing a large run.
